# 🤖 Curiosidades de Tecnologia – Mascote Android

Projeto desenvolvido com o objetivo de praticar **HTML5 semântico**, **CSS3**, responsividade e organização de conteúdo, baseado nos estudos do **Curso em Vídeo**.

O site apresenta a história do mascote do Android, desde suas primeiras versões até o Bugdroid atual, utilizando boas práticas de estruturação e acessibilidade.

---

## 📸 Preview

Projeto responsivo com adaptação para dispositivos móveis e desktop.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts
- Fonte local (`@font-face`)
- Responsividade com `<picture>`
- Embeds de vídeo (YouTube)

---

## 📚 Conceitos Praticados

- HTML semântico (`header`, `nav`, `main`, `article`, `aside`, `footer`)
- Hierarquia correta de títulos (`h1`, `h2`, `h3`)
- Uso de variáveis CSS (`:root`)
- Fontes externas e locais
- Gradientes e estilização moderna
- Links externos com `target="_blank"`
- Responsividade de imagens
- Organização de conteúdo para leitura

---

## 🧠 Aprendizados

Este projeto reforçou conceitos importantes para desenvolvimento Front-End, como:
- Estruturação correta de páginas
- Separação de responsabilidades entre HTML e CSS
- Boas práticas visuais e de usabilidade
- Criação de layouts limpos e organizados
